זה טקסט לדוגמה בלבד. הוא כאן כדי לראות איך נראים כותרות, רשימות, טיפים וקוד בעמוד מדריך. כשהמדריך הראשון מוכן, מוחקים את הקובץ הזה.

## כותרת של שלב

פסקה רגילה. אפשר **להדגיש מילים** ולשים [קישור לעמוד האינסטגרם](https://www.instagram.com/ilaybuilds/).

1. צעד ראשון
2. צעד שני
3. צעד שלישי

## עוד שלב

- נקודה אחת
- נקודה שנייה

> טיפ: ככה נראית הערה חשובה.

פקודה להעתקה, וגם `קוד קצר` בתוך שורה:

```bash
npm run dev
```

### כותרת קטנה

עוד פסקה, כדי לראות את הרווחים בין החלקים.
